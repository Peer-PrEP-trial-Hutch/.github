## Introduction

This is the master repository for multiple projects derived from the Peer PrEP clustered randomized trial ([ClinicalTrials.gov: NCT04982250](https://clinicaltrials.gov/study/NCT04982250?cond=HIV&titles=Peer%20PrEP&rank=1)).
